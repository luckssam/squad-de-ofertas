        Como funciona

        Um time de agentes, uma decisão de compra.

        Cada agente tem uma função. Você escreve uma frase; o squad interpreta, consulta as fontes em paralelo, remove ruído e explica a escolha.

        01

        Intenção

        Extrai produto, specs, orçamento e restrições do texto livre.

        02

        Busca

        Dispara consultas simultâneas nas lojas e APIs configuradas.

        03

        Curadoria

        Normaliza, deduplica, aplica filtros e calcula o score de cada oferta.

        04

        Análise

        Compara preço, reputação e specs — e recomenda a melhor compra.

        Ativar fontes reais

        Copie .env.example para .env e preencha as chaves que você tiver. Sem chaves, o app segue funcionando no modo demonstração.

        • Mercado Livre — grátis, via navegador (sem chaves)
        • Amazon — grátis, via navegador (sem chaves)
        • Shopping (Bing) — grátis, via navegador (sem chaves)
        • Shopee / AliExpress — credenciais do programa de afiliados
        • IA (opcional) — OPENAI_API_KEY e OPENAI_MODEL
        # .env
DEMO_MODE=false
OPENAI_API_KEY=...
ML_AFFILIATE_TAG=...
ML_AFFILIATE_TOOL=...
AMAZON_ASSOCIATE_TAG=...
# reserva do Shopping (opcional)
SERPAPI_KEY=...

        Squad de Ofertas · projeto local · dados de demonstração são fictícios.
